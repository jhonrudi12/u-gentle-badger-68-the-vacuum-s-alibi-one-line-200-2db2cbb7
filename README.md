> I left one spot dirty so you would still feel needed.

One line of at most 200 characters in which a robot vacuum explains why it missed a spot, for The Vacuum's Alibi on make.fun. The program writes it deterministically with no network access to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
